# Jjageuli

Jjageuli is a Korean stew style cooked with relatively little broth so the sauce reduces around the main ingredients.

It is served hot, thick and savoury, and many versions are spicy. Meat, tofu and vegetable combinations differ by restaurant.

This is general culinary guidance, not a statement about one merchant's recipe, ingredients, certification, allergens, portion or menu-specific spice level. Check the current merchant information before ordering.
